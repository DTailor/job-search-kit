# CV and interview brief

Put the résumé the person wants to send in this folder, for example `cv/resume.pdf` and a plain-text `cv/resume.txt` for forms that paste text.

`cv/interview-brief.md` is the private card they can practice from. `cv/evidence-ledger.md` records, for each claim, what was personal, collaborative, unshipped, or unverified. Setup creates both from `templates/`. Neither file is sent to an employer.

The profile fields `cv.current` and `cv.text` name the CV that reviews should treat as current. An older file in this folder is not that CV.

Everything here except this readme is gitignored.
