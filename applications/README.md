# Applications

One folder per submitted application: `applications/<company>_<role-slug>/`.

- `posting.md`: the posting text saved when they apply. Postings disappear.
- `application.md`: date, route, CV used, money asked, the words that were actually sent, and a timeline.
- `prep.md`: interview pack from `commands/job-interview.md`.

Start each file from `templates/`. The archive records what already happened. Saving a posting is not permission to apply.

Status lives in `tracker/roles.csv`. This folder is the evidence. It is gitignored except for this readme.
