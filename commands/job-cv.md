# CV review

Review the public CV against the private evidence. Do not invent employers, dates, metrics, or titles.

1. If the profile is not `ready`, follow `SETUP.md` and stop.
2. Read `profile/profile.yml`, `profile/PROFILE.md`, `cv/interview-brief.md`, and `cv/evidence-ledger.md`. The current CV is the file named in `cv.current`, with the plain text in `cv.text` when that path is set. An older source is not the current CV. If a file is missing, say so.
3. Check each public claim. It has a source in the brief or the ledger. Adjacent skills are not the headline. `evidence.do_not_claim` does not appear. Metrics have a guardrail. Internal names, customer names, and ticket ids are absent. Employers that the person kept distinct stay distinct. Work the ledger marks unshipped is not written as an achievement.
4. Report what a recruiter would misread, what to cut, and which gaps need the person. Offer replacement wording only for claims the evidence supports.
5. Leave LinkedIn alone when `linkedin.headline_locked` is true. Do not add wording that advertises an active search when `linkedin.advertise_search` is false.

Do not send the brief, the ledger, or a revised CV unless this message asks for that.
